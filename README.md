# مرصد السماء — Sky Tracker

تطبيق ويب عربي لتتبع القمر والكواكب المشهورة من موقع المستخدم أو من مدن سعودية مختارة.

## ما الذي يعرضه؟
- موقع القمر وعطارد والزهرة والمريخ والمشتري وزحل.
- اتجاه الجرم وارتفاعه فوق الأفق.
- وقت وجهة الشروق والغروب.
- أعلى ارتفاع وأفضل وقت للرصد.
- الليالي المناسبة للرصد خلال 7 أيام و30 يومًا.
- طور القمر ونسبة إضاءته.
- دعم تحديد الموقع من الهاتف بعد موافقة المستخدم.

## التقنية
الموقع يعمل كصفحة ثابتة على GitHub Pages ويستخدم Astronomy Engine للحسابات الفلكية. لا يحتاج إلى Firebase أو تسجيل دخول.

## الأيقونة
أيقونة خاصة بمرصد السماء تظهر داخل التطبيق وفي ملف الـ PWA، بتصميم يجمع الهلال والكوكب ذي الحلقات والجبال الليلية.
